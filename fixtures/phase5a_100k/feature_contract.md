# Phase 5A additive feature contract v1

This contract maps the SIH26146 feature families to the actual Phase 4/4.1 address-plus-time-window exporter (`GET /v1/cases/{case_id}/features/export`). It is additive documentation only: the frozen `feature_schema.json` remains unchanged and no synthetic feature-export file is fabricated here. Every exported row is tied to a case, immutable snapshot, graph snapshot, window boundaries, coverage, and source references.

The current exporter materializes 15-minute, 1-hour, and 24-hour windows (`WINDOW_SECONDS = 900, 3600, 86400`). Its feature vector uses `deterministic-v1` for aggregate values and the response carries `phase4.1-feature-v1` as the frozen Phase 4.1 schema version.

Model-input eligibility is a later, versioned preparation decision. This fixture supplies no model-input table. At minimum exclude wallet/address/script values, raw IP/endpoints, TXIDs, case/source identifiers and locators, scenario labels, split/group IDs, seed identities/reasons, reviewer decisions, and all future information. The synthetic seed fields are explicitly metadata-only under the frozen handoff.
