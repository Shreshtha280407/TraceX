## Coverage beyond the core matrix

- `tests/e2e/test_boot_smoke.py` — end-to-end boot + `/healthz` → `/readyz` → `/api/v1/meta/contracts` sequence against a real ASGI app instance.
- `tests/integration/test_readiness_live.py` — real connections to PostgreSQL/Neo4j/Redis/MinIO when a real `.env` and running infrastructure are present; self-skips per-dependency otherwise (never fabricates a pass).
- `tests/security/test_no_secret_leakage.py` — the generic unhandled-exception handler and `/readyz` never echo exception text or secrets, independent of any specific route.
- `tests/integration/graph/` — real Neo4j projection/query/schema/isolation checks when a real `.env` and running Neo4j are present; self-skips otherwise, mirroring `test_readiness_live.py`'s pattern exactly (see `docs/architecture/neo4j-graph-foundation.md`).
- `tests/integration/structured_processing/test_local_file_pipeline.py` — the full `process_job` pipeline across every content kind via a real local-file-backed `SourceResolver` (not `StaticBytesResolver`). No external service is needed, so this doesn't self-skip.
- `tests/integration/access_control/` — real PostgreSQL/Redis checks (migration apply, full register/login/refresh/logout round trip, refresh-token hashing, token-family revocation, live case-membership/clearance decisions, Redis-backed rate limiting) when a real `.env` and running infrastructure are present; self-skips otherwise, mirroring `test_readiness_live.py`'s pattern exactly (see `docs/architecture/access-control-v1.md`).
- `tests/security/access_control/test_module_boundaries.py` — static AST check that the access-control module never imports `app.modules.graph`/`app.modules.structured_processing` or any OCR/media/vector/ML library.
